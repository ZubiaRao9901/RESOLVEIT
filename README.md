ResolveIT – IT Service & Incident Management System

ResolveIT is a web-based IT Service Management system developed using Python, FastAPI, HTML, CSS, JavaScript, and SQLite. It allows users to report IT issues, generate unique ticket IDs, track ticket status, assign tickets to engineers, and manage incidents through an interactive dashboard.

The system helps organize IT support requests, monitor ticket progress, and improve incident management through a simple and user-friendly interface.
